
# Домены
1. Медицинский AI домен - анализ AI медицинских данных клиентов компании
2. Домен аналитики - домен формирования витрины данных: bi, аналитика, отчеты и т.д.
3. Медицинский домен - домен для работы с медицинскими данными: карточками пациентов, анализами и т.д.
4. Пользовательский домен - домен клиентов компании: персональные данные, история медицинского обслуживания и т.д.
5. Фин. Тех. домен - домен отвечает за финансовые операции: финансовые операции, счета, история транзакций и т.д.
6. DWL

# Аргументация
1. Разделение потоков данных способствует формированию регламента работы с конфиденциальными и персональными данными и соответствию ФЗ-152
2. Возможность проектирования системы согласно подходу DDD
3. Возможность масштабировать систему
4. Разделение ответственности команд по доменам
5. Возможность внедрения слабой связанности между доменами, в т.ч. каждый домен работает с данными необходимыми для системы
6. Возможно разграничить доступ в данным
